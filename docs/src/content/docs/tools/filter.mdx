Drop folders onto **File Tree** on the left (or use **Load**). The tabs on the right work on everything in the
tree.

![The Filter panel: a folder in File Tree and its files grouped by Types](/img/filter-light.png)

| Tab | What it shows or does |
| --- | --- |
| **Archives** | Every archive (zip, rar, 7z, …) and its contents; **Extract All** unpacks them with 7-Zip |
| **Types** | Files grouped by type: episode, movie, movie folder, subtitles, audio, images, archives, … |
| **Parts** | Splits the files into volumes of a size you choose (**Split every … MB**), for example to fit discs |
| **Attributes** | The data FileBot Pro stored on each file when it was renamed. **Apply** does the chosen actions for the selected rows (or all of them): artwork, cover, NFO, URL, Tags, SRT, Finder Tags, Touch, Chmod or Date (see below) |
| **MediaInfo** | Video, audio and subtitle properties of every media file |

Right click a file or folder in the tree to **Send to** another panel, **Reveal** it or **Reveal Folder** in your file
manager, or **Move to Trash**.

:::tip
**MediaInfo** needs the MediaInfo library: see [native tools](/reference/configuration/#native-tools).
:::

## Attributes

Tick the actions you want, then press **Apply**:

| Action | What it does |
| --- | --- |
| Artwork | Downloads posters, backdrops and episode thumbnails |
| Cover | Writes `cover.jpg` for each folder, reusing local posters before downloading one |
| NFO | Writes `.nfo` files for Kodi, Plex, Emby and Jellyfin |
| URL | Writes a `.url` shortcut to the movie or series page |
| Tags | Writes title, series, season, episode and date into mkv (mkvpropedit) and mp4 (AtomicParsley) files, and attaches the cover |
| SRT | Converts subtitle files to SubRip (`.srt`) with UTF-8 encoding |
| Finder Tags | Adds Finder tags for the media type, video format and HDR (macOS) |
| Touch | Sets the last modified date to now |
| Chmod | Sets the file permissions to the default |
| Date | Sets the last modified date to the release or air date |

## MediaInfo views

The **MediaInfo** tab shows every property by default. To see only the columns you care about, create a view:

1. Click **Columns …**. Pick columns from **Available columns** (use the filter box to find them) and move them with
   the arrow button; double click works too. Order them with the up and down buttons.
2. A column that isn't in the loaded files yet can be typed by name, e.g. `Video.Width` or `Audio[1].Language`.
3. Give the view a name and **Save**. It's selected right away and remembered next time.

Switch views with the **View** list. The **⋯** button next to it can create, duplicate, rename and delete views, and
**Export** or **Import** them as `.json` files to share them or move them to another computer. The **Default** view
can't be changed: editing its columns starts a new view.

Column widths are remembered for each view, the **Default** view included: drag a column border once and it keeps that
width when you switch views or load other files.
