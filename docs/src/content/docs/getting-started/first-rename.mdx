<Steps>

1. **Add your files.** Open the **Rename** panel (`Ctrl`+`1`) and drag files or whole folders into
   **Original Files**, or use **Load**.

2. **Fetch the data.** Click **Fetch Data** below **New Names** and pick a source: TheTVDB, AniDB,
   TheMovieDB::TV or TVmaze for episodes, TheMovieDB or OMDb for movies, AcoustID or ID3 for music.
   **Autodetect** decides for each file.

3. **Confirm the show.** When a name is ambiguous, FileBot Pro asks you to pick the right show or movie.
   Select it and press **Select**; tick the checkbox to remember the choice.

4. **Check the result.** Each original file sits next to its new name. Dimmed rows have no counterpart;
   remove them with `Delete` or line them up with the arrows and press **Match**.

5. **Rename.** Click the orange **Rename** button. Every operation is recorded in the
   [history](/tools/rename/#history), so it can be undone.

</Steps>

## Choose how files are named

The new names come from a [format expression](/formats/syntax/). Open **Fetch Data** › **Edit Format** to
change it. A good start for a media server:

```groovy title="Episodes"
{plex}
```

```groovy title="Movies"
{n} ({y})/{n} ({y})
```

The editor previews the result for a sample file while you type.

## Copy, link or move

The gear button next to **Fetch Data** sets the **rename action**: rename/move (the default), copy, keeplink
(move and leave a link behind), symlink, hardlink or clone (macOS and Linux). The icon of the **Rename**
button changes with the action, so you always know what is going to happen.
