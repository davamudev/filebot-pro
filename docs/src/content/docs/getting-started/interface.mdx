## Navigation

The rail on the left switches between the six tools. `Ctrl`+`1` to `Ctrl`+`6` (`⌘` on macOS) jump to them
directly.

| Panel | What it does |
| --- | --- |
| **Rename** | Matches files with movie, episode and music data and renames them |
| **Episodes** | Browses and exports episode lists |
| **Subtitles** | Searches and downloads subtitles |
| **SFV** | Creates and verifies checksum files |
| **Filter** | Inspects media properties, extracts archives and splits folders |
| **List** | Generates numbered lists of names |

Hover an item to see its shortcut. Dragging files over an item for a moment opens that panel, so you can
carry files from one tool to another.

## Themes

The **Appearance** button at the bottom of the rail offers **Follow system**, **Light** and **Dark**. With
**Follow system** FileBot Pro switches by itself when your operating system does, with a short cross-fade.

![The Episodes panel in dark mode](/img/episodes-dark.png)

## Feedback

- **Notifications** slide in at the bottom right: information, warnings and errors. Click one to copy its
  text.
- **Long tasks** such as renaming many files show a progress dialog that can be cancelled with `Esc`.
- **Empty lists** tell you what to drop into them, and lists light up while you drag files over them.

![Checksums in light mode](/img/sfv-light.png)

## Help menu

The **Help** button at the bottom of the rail links to this documentation (getting started, format
expressions, FAQ, troubleshooting) and shows the welcome screen again. `F1` opens the documentation from
anywhere.
