---
title: Keyboard shortcuts
description: Every keyboard shortcut of the desktop app.
---

On macOS use `⌘` instead of `Ctrl`, and `Backspace` also works where `Delete` is listed.

## Everywhere

| Shortcut | Action |
| --- | --- |
| `Ctrl`+`1` … `Ctrl`+`6` | Rename, Episodes, Subtitles, SFV, Filter, List |
| `F1` | Open the documentation |
| `F5` | Open the script editor |
| `Ctrl`+`Shift`+`Delete` | Clear the cache |
| `Esc` | Close the dialog or cancel the running task |
| `Ctrl`+`Z` / `Ctrl`+`Y` | Undo and redo in text fields |

## Lists

| Shortcut | Action |
| --- | --- |
| `Delete` | Remove the selected rows |
| `Enter` | Select, download or open, depending on the list |

## Rename

| Shortcut | Action |
| --- | --- |
| `1` … `9` | Apply the preset with that [shortcut](/tools/rename/#presets) |
| `F2` | Plain file mode: use the file names as they are, so the file format decides the new names |
| `F3` | Local xattr mode: use the data stored on earlier renames, without looking anything up |
| `F6` or `Space` | Show or hide the [match details](/tools/rename/#match-details) below the lists |
| `F7` | Copy the debug information of the match to the clipboard (for bug reports) |
| `Esc` | Cancel **Fetch Data** while it runs |
| `Ctrl`+`O` | Open the selected file |
| `Ctrl`+`L` | Reveal the selected file in its folder |
| `Ctrl`+`M` | Edit the match of the selected file (search the series or movie again) |
| `Ctrl`+`N` | Edit the new name of the selected file |
| `Ctrl`+`Shift`+`N` | Edit all new names at once (or the selected ones) |

## Search panels

| Shortcut | Action |
| --- | --- |
| `Enter` | Search |
| `Ctrl`+`↑` / `Ctrl`+`↓` | Switch the source |
| `Shift`+`↑` / `Shift`+`↓` | Change the season (Episodes) |

## Editors

| Shortcut | Action |
| --- | --- |
| `F1` | Show or hide the syntax help (format editor) |
| `F5` or `Ctrl`+`R` | Run the script (script editor) |
