---
title: Atajos de teclado
description: Todos los atajos de teclado de la aplicación de escritorio.
---

En macOS usa `⌘` en lugar de `Ctrl`; donde pone `Supr` también vale `Retroceso`.

## En cualquier sitio

| Atajo | Acción |
| --- | --- |
| `Ctrl`+`1` … `Ctrl`+`6` | Rename, Episodes, Subtitles, SFV, Filter, List |
| `F1` | Abre la documentación |
| `F5` | Abre el editor de scripts |
| `Ctrl`+`Mayús`+`Supr` | Borra la caché |
| `Esc` | Cierra la ventana o cancela la tarea en curso |
| `Ctrl`+`Z` / `Ctrl`+`Y` | Deshacer y rehacer en los campos de texto |

## Listas

| Atajo | Acción |
| --- | --- |
| `Supr` | Quita las filas seleccionadas |
| `Intro` | Selecciona, descarga o abre, según la lista |

## Rename

| Atajo | Acción |
| --- | --- |
| `1` … `9` | Aplica el preset con ese [atajo](/es/tools/rename/#presets) |
| `F2` | Modo archivo simple: usa los nombres de archivo tal cual, para que el formato de archivo decida los nombres nuevos |
| `F3` | Modo xattr local: usa los datos guardados en renombrados anteriores, sin buscar nada |
| `F6` o `Espacio` | Muestra u oculta los [detalles del emparejado](/es/tools/rename/#detalles-del-emparejado) debajo de las listas |
| `F7` | Copia la información de depuración del emparejado al portapapeles (para informes de error) |
| `Esc` | Cancela **Fetch Data** mientras se ejecuta |
| `Ctrl`+`O` | Abre el archivo seleccionado |
| `Ctrl`+`L` | Muestra el archivo seleccionado en su carpeta |
| `Ctrl`+`M` | Edita el emparejado del archivo seleccionado (vuelve a buscar la serie o película) |
| `Ctrl`+`N` | Edita el nombre nuevo del archivo seleccionado |
| `Ctrl`+`Shift`+`N` | Edita todos los nombres nuevos a la vez (o los seleccionados) |

## Paneles de búsqueda

| Atajo | Acción |
| --- | --- |
| `Intro` | Buscar |
| `Ctrl`+`↑` / `Ctrl`+`↓` | Cambia la fuente |
| `Mayús`+`↑` / `Mayús`+`↓` | Cambia la temporada (Episodes) |

## Editores

| Atajo | Acción |
| --- | --- |
| `F1` | Muestra u oculta la ayuda de sintaxis (editor de formato) |
| `F5` o `Ctrl`+`R` | Ejecuta el script (editor de scripts) |
