## Navegación

La barra de la izquierda cambia entre las seis herramientas. `Ctrl`+`1` a `Ctrl`+`6` (`⌘` en macOS) saltan
directamente a cada una.

| Panel | Para qué sirve |
| --- | --- |
| **Rename** | Empareja archivos con datos de películas, episodios y música y los renombra |
| **Episodes** | Consulta y exporta listas de episodios |
| **Subtitles** | Busca y descarga subtítulos |
| **SFV** | Crea y comprueba archivos de sumas de verificación |
| **Filter** | Analiza propiedades multimedia, extrae archivos comprimidos y reparte carpetas |
| **List** | Genera listas numeradas de nombres |

Pasa el ratón por un elemento para ver su atajo. Si arrastras archivos sobre un elemento durante un momento,
se abre ese panel: así llevas archivos de una herramienta a otra.

## Temas

El botón **Appearance** de la parte inferior ofrece **Follow system**, **Light** y **Dark**. Con
**Follow system**, FileBot Pro cambia solo cuando lo hace tu sistema, con un fundido corto.

![El panel Episodes en modo oscuro](/img/episodes-dark.png)

## Avisos

- Las **notificaciones** aparecen abajo a la derecha: información, avisos y errores. Haz clic en una para copiar
  su texto al portapapeles; la notificación se cierra.
- Las **tareas largas**, como renombrar muchos archivos, muestran una ventana de progreso que se cancela con el
  botón **Cancel** o con `Esc`.
- Las **listas vacías** indican qué puedes soltar en ellas y se iluminan mientras arrastras archivos encima.

![Sumas de verificación en modo claro](/img/sfv-light.png)

## Menú de ayuda

El botón **Help** de la parte inferior abre enlaces a esta documentación (primeros pasos, expresiones de formato,
preguntas frecuentes, diagnóstico). También vuelve a mostrar la pantalla de bienvenida y ofrece:

- **System properties…**: versiones, herramientas nativas y carpetas (lo mismo que `fn:sysinfo` en la línea de comandos).
- **Export user data…** y **Restore user data…**: guarda o restaura tus ajustes, presets e historial en un archivo zip.
- **About**: la versión de FileBot Pro.

`F1` abre la documentación desde cualquier sitio.
