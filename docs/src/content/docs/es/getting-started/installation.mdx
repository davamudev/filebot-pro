## Requisitos

| | |
| --- | --- |
| **Sistema operativo** | Windows 10/11, Linux (Ubuntu, Debian, Fedora y otras), macOS, de 64 bits, o un NAS Synology con DSM 7.0 o posterior |
| **Java** | Incluido en todas las descargas |
| **Internet** | Para buscar películas, episodios, subtítulos e imágenes |

## Descargas

Descarga el archivo de tu sistema desde la [página de versiones](https://github.com/davamudev/filebot-pro/releases).
Los ejemplos de esta página usan la versión `1.0.0`.

| Sistema | Archivos |
| --- | --- |
| Windows (x64) | `FileBot-Pro-1.0.0.msi` (instalador) o `FileBot-Pro-1.0.0-windows-portable.zip` |
| Windows (ARM) | `FileBot-Pro-1.0.0-windows-arm64-portable.zip` |
| macOS, Apple Silicon | `FileBot-Pro-1.0.0-arm64.dmg` o `FileBot-Pro-1.0.0-macos-arm64-portable.zip` |
| macOS, Intel | `FileBot-Pro-1.0.0-x64.dmg` o `FileBot-Pro-1.0.0-macos-x64-portable.zip` |
| Ubuntu, Debian | `filebot-pro_1.0.0_amd64.deb` |
| Fedora, openSUSE | `filebot-pro-1.0.0-1.x86_64.rpm` |
| Otro Linux | `FileBot-Pro-1.0.0-linux-portable.zip` |
| NAS Synology | `FileBot-Pro-1.0.0-synology-x86_64.spk` (Intel y AMD) o `FileBot-Pro-1.0.0-synology-armv8.spk` (ARM de 64 bits) |
| Docker | `ghcr.io/davamudev/filebot-pro`, consulta [Docker y NAS](/es/getting-started/docker/) |

Cada versión incluye también `SHA256SUMS.txt`. Para comprobar una descarga, compara su hash SHA-256 con la línea
correspondiente de ese archivo: `sha256sum` en Linux, `shasum -a 256` en macOS, `certutil -hashfile <archivo> SHA256` en Windows.

:::caution[Las versiones todavía no están firmadas]
Windows y macOS avisan la primera vez que abres FileBot Pro. En Windows, SmartScreen muestra **Windows protegió su PC**:
haz clic en **Más información** y después en **Ejecutar de todos modos**. En macOS, consulta la pestaña de macOS más abajo.
:::

<Tabs syncKey="os">
<TabItem label="Windows">

**Portable (recomendado)**: no se instala nada y no se escribe nada fuera de la
[carpeta de datos](/es/reference/configuration/#datos-de-usuario).

<Steps>

1. Descomprime `FileBot-Pro-1.0.0-windows-portable.zip` (`FileBot-Pro-1.0.0-windows-arm64-portable.zip` en equipos
   ARM, como los portátiles Snapdragon) donde quieras: el escritorio, `Archivos de programa` o un USB.

2. Abre **FileBot Pro.exe**. En la misma carpeta está `filebot-pro.exe`, la versión de línea de comandos.

</Steps>

**Instalador**: ejecuta `FileBot-Pro-1.0.0.msi` y abre **FileBot Pro** desde el menú de inicio o el acceso directo
del escritorio. El instalador pregunta si quieres crear cada acceso directo, añadir `filebot-pro` al `PATH` y añadir
FileBot Pro al menú contextual del Explorador (todo viene marcado). Para una instalación silenciosa sin la entrada del `PATH`
ni la integración con el Explorador: `msiexec /i FileBot-Pro-1.0.0.msi /qn ADD_TO_PATH=0 EXPLORER_INTEGRATION=0`. Añade
`JP_INSTALL_DESKTOP_SHORTCUT=""` y `JP_INSTALL_STARTMENU_SHORTCUT=""` para omitir los accesos directos (con `=0` se siguen creando).

Con la integración con el Explorador, las carpetas, unidades y archivos de vídeo y subtítulos muestran **Open in FileBot Pro**
al hacer clic derecho (en Windows 11, dentro de **Mostrar más opciones**), y **Enviar a → FileBot Pro** abre cualquier
selección, también de más de 15 archivos. Si FileBot Pro ya está abierto, los archivos van a esa ventana.

MediaInfo, fpcalc, mkvpropedit y AtomicParsley vienen incluidos en los dos.

</TabItem>
<TabItem label="Ubuntu / Debian">

<Steps>

1. Añade el repositorio de FileBot Pro (firmado con su propia clave) e instala el paquete:

   ```bash
   sudo install -d -m 0755 /etc/apt/keyrings
   sudo wget -qO /etc/apt/keyrings/filebot-pro.asc https://apt.davamu.dev/filebot-pro.asc
   sudo wget -qO /etc/apt/sources.list.d/filebot-pro.sources https://apt.davamu.dev/filebot-pro.sources
   sudo apt update
   sudo apt install filebot-pro
   ```

   `apt` instala también los paquetes recomendados: MediaInfo, fpcalc (`chromaprint-tools`), mkvtoolnix y
   AtomicParsley. Las propiedades multimedia, el reconocimiento de música y la escritura de metadatos funcionan desde el
   principio. Las versiones nuevas llegan con el resto de actualizaciones (`sudo apt update && sudo apt upgrade` o el
   Actualizador de software).

   Sin el repositorio, instala el paquete descargado desde su carpeta con
   `sudo apt install ./filebot-pro_1.0.0_amd64.deb`; cada actualización es entonces una descarga nueva.

2. Abre **FileBot Pro** desde el menú de aplicaciones o escribe `filebot-pro` en una terminal.

</Steps>

La aplicación se instala en `/opt/filebot-pro` y el comando `filebot-pro` en `/usr/bin`, con autocompletado
para bash. Funciona en Ubuntu 22.04 o posterior, Debian 12 o posterior y derivadas como Linux Mint, Pop!_OS o elementary OS.

</TabItem>
<TabItem label="Fedora / RPM">

<Steps>

1. Instala el paquete con `dnf` (o `zypper` en openSUSE):

   ```bash
   sudo dnf install ./filebot-pro-1.0.0-1.x86_64.rpm
   ```

2. Abre **FileBot Pro** desde el menú de aplicaciones o escribe `filebot-pro` en una terminal.

</Steps>

`dnf` instala también los paquetes recomendados si están disponibles: MediaInfo (`libmediainfo`), fpcalc
(`chromaprint-tools`), mkvtoolnix y AtomicParsley. El comando `filebot-pro` tiene autocompletado para bash.

</TabItem>
<TabItem label="Otro Linux">

<Steps>

1. Descomprime `FileBot-Pro-1.0.0-linux-portable.zip` donde quieras, por ejemplo en `~/Applications`.

2. Ejecuta `FileBot Pro/bin/FileBot Pro` para la aplicación de escritorio o `FileBot Pro/bin/filebot-pro` para
   la línea de comandos.

3. Opcional: enlaza el comando en tu `PATH`:

   ```bash
   ln -s "$HOME/Applications/FileBot Pro/bin/filebot-pro" ~/.local/bin/filebot-pro
   ```

4. Instala MediaInfo y fpcalc con tu gestor de paquetes: consulta
   [herramientas nativas](/es/reference/configuration/#herramientas-nativas).

</Steps>

</TabItem>
<TabItem label="macOS">

<Steps>

1. Abre `FileBot-Pro-1.0.0-arm64.dmg` (Apple Silicon, M1 y posteriores) o `FileBot-Pro-1.0.0-x64.dmg` (Intel) y
   arrastra **FileBot Pro** a **Aplicaciones**. Los archivos `-macos-…-portable.zip` contienen la misma aplicación sin la imagen de disco.

2. Las versiones todavía no están firmadas. Si macOS no deja abrir la aplicación la primera vez, ve a
   **Ajustes del Sistema → Privacidad y seguridad** y pulsa **Abrir igualmente**.

3. Instala MediaInfo y fpcalc con [Homebrew](https://brew.sh):

   ```bash
   brew install libmediainfo chromaprint
   ```

</Steps>

Los archivos de vídeo y subtítulos muestran **FileBot Pro** en el menú **Abrir con** del Finder (nunca pasa a ser
la aplicación predeterminada para ellos).

</TabItem>
</Tabs>

En un NAS Synology, instala el paquete `.spk` o ejecuta la imagen Docker, consulta [Docker y NAS](/es/getting-started/docker/#nas).

En Linux, los archivos de vídeo y subtítulos también muestran **FileBot Pro** en **Abrir con**, y la aplicación usa
el diálogo de archivos de tu escritorio si está instalado `zenity` (GNOME y la mayoría) o `kdialog` (KDE).

Para compilar FileBot Pro tú mismo, consulta [compilar desde el código](/es/development/building/).

En el primer arranque aparece la pantalla de bienvenida. Ciérrala o sigue el enlace a
[tu primer renombrado](/es/getting-started/first-rename/).

## Línea de comandos

Todas las descargas incluyen el comando `filebot-pro` para scripts, servidores y automatización. Sin argumentos
abre la aplicación de escritorio; con argumentos ejecuta el comando y termina.

| Sistema | Comando |
| --- | --- |
| Windows | `filebot-pro`, en el `PATH` con el instalador (abre una terminal nueva después de instalar). Portable: `filebot-pro.exe` en la carpeta |
| Ubuntu, Debian, Fedora | `filebot-pro`, ya está en el `PATH` |
| Otro Linux | `FileBot Pro/bin/filebot-pro` |
| macOS | `filebot-pro` después de Ayuda → **Install 'filebot-pro' command…** en la aplicación, que pide la contraseña de administrador. Sin eso: `"/Applications/FileBot Pro.app/Contents/MacOS/FileBot Pro"` |

```bash
filebot-pro -script fn:sysinfo                        # versiones, herramientas nativas y carpeta de datos
filebot-pro -rename "/media/TV" --db TVmaze --action test --format "{n} - {s00e00} - {t}"
filebot-pro -script fn:amc "/downloads/complete" --output "/media" --action move -non-strict
```

En Linux la línea de comandos no necesita una sesión de escritorio, así que también funciona por SSH y en
servidores. Consulta la [referencia de la línea de comandos](/es/reference/command-line/) para ver todas las
opciones.

## Lista para el primer arranque

- **Bases de datos en línea**: listas para usar. Solo OMDb y la ubicación de las fotos necesitan tu
  propia clave gratuita, consulta [claves API](/es/reference/configuration/#claves-api).
- **Propiedades multimedia**: comprueba con `filebot-pro -script fn:sysinfo` que se han encontrado MediaInfo y
  fpcalc. Si no, consulta [herramientas nativas](/es/reference/configuration/#herramientas-nativas).
- **Tema**: FileBot Pro sigue el modo claro u oscuro del sistema. Cámbialo con el botón **Appearance** de la
  parte inferior de la navegación.

:::note[Sin licencia]
Todo es gratis, también renombrar: FileBot Pro no necesita licencia ni cuenta, y las bases de datos en línea
están listas para usar.
:::

## Actualizar

FileBot Pro avisa cuando sale una versión nueva, pero no se actualiza solo:

- **Aplicación de escritorio**: un diálogo al arrancar con las notas de versión, **Download** (abre la página de la
  release), **Skip this version** y **Later**. Se desactiva en Ayuda → **Check for updates at startup**.
- **Línea de comandos**: un aviso en stderr al terminar el comando, como mucho una vez al día y solo en una consola
  interactiva, así que los scripts y las tareas programadas no lo ven. `filebot-pro -script fn:sysinfo` también lo
  muestra.
- **Docker**: una línea en el log del contenedor (consulta [actualizar la imagen](/es/getting-started/docker/#actualizar)).

Para desactivarlo en todas partes, añade `application.update=skip` a las propiedades del sistema (Ayuda → **System
properties…**) o pasa `-Dapplication.update=skip`.

Lo que cambió en cada versión está en las [notas de versión](/es/reference/releases/#notas-de-versión). Después
descarga la versión nueva de la [página de releases](https://github.com/davamudev/filebot-pro/releases/latest):

| Paquete | Cómo |
|---|---|
| Instalador de Windows (`.msi`) | Ejecuta el instalador nuevo, sustituye la versión instalada |
| Zip portable | Sustituye la carpeta de la aplicación |
| macOS (`.dmg`) | Sustituye la aplicación en Aplicaciones |
| Debian / Ubuntu | Con el repositorio, `sudo apt update && sudo apt upgrade`; si no, `sudo apt install ./<nuevo>.deb` |
| Fedora / RHEL | `sudo dnf install ./<nuevo>.rpm` |
| Synology | Centro de paquetes → Instalación manual con el `.spk` nuevo |

Los ajustes, el historial y los presets viven en la [carpeta de datos](/es/reference/configuration/#datos-de-usuario)
y se conservan.

## Desinstalar

| Sistema | Cómo |
| --- | --- |
| Windows | **Configuración → Aplicaciones**, o borra la carpeta portable |
| Ubuntu, Debian | `sudo apt remove filebot-pro` y, para quitar el repositorio, `sudo rm /etc/apt/sources.list.d/filebot-pro.sources /etc/apt/keyrings/filebot-pro.asc` |
| Fedora | `sudo dnf remove filebot-pro` |
| macOS | Mueve **FileBot Pro** de **Aplicaciones** a la papelera. Si instalaste el comando `filebot-pro`, quítalo antes con Ayuda → **Remove 'filebot-pro' command…** |

La [carpeta de datos](/es/reference/configuration/#datos-de-usuario) se conserva; bórrala también para eliminar
los ajustes, el historial y las cachés.
