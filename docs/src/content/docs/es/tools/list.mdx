---
title: Lista
description: Genera listas numeradas de nombres a partir de una expresión de formato.
---

Escribe un **Pattern** con `{i}` (el índice), elige el rango con **From** y **To** y pulsa **Sequence**.

```groovy title="Pattern"
Sequence - {i.pad(2)}
```

genera `Sequence - 01`, `Sequence - 02`, … El patrón es una [expresión de formato](/es/formats/syntax/)
completa.

Si sueltas archivos, una carpeta o un torrent sobre la lista, se listan sus nombres, listos para darles forma
con el patrón.

Haz clic derecho en la lista para enviarla a **Rename** como nombres nuevos (**Send to**), copiarla (**Copy**)
o guardarla en un archivo de texto (**Save as ...**).
