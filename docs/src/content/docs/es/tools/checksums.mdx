## Comprobar

Suelta un archivo de sumas (`.sfv`, `.md5`, `.sha1`, `.sha256`, `.sha3`) o una carpeta entera sobre la tabla.
Cada archivo se calcula y se compara, y la columna **State** muestra el resultado de cada uno.

Un CRC32 en el nombre de un archivo (por ejemplo `[A1B2C3D4]`) también se comprueba, así que una versión se
puede verificar sin archivo de sumas.

## Crear

Suelta los archivos que quieras proteger, elige el tipo de suma debajo de la tabla y pulsa **Save as ...**.

| Botón | Algoritmo | Archivo |
| --- | --- | --- |
| SFV | CRC32 | `.sfv` |
| MD5 | MD5 | `.md5` |
| SHA1 | SHA-1 | `.sha1` |
| SHA2 | SHA-256 | `.sha256` |
| SHA3 | SHA3-384 | `.sha3` |

Las rutas del archivo guardado son relativas a la carpeta donde lo guardas, así que se puede guardar en cualquier
sitio (los archivos de otra unidad conservan su ruta completa). Los archivos SFV usan saltos de línea de Windows y
los MD5 y SHA saltos de línea de Unix, como `md5sum`. Los archivos cuya suma aún se está calculando se omiten, con
un aviso.

Cambiar el tipo de suma recalcula la tabla. **Clear** la vacía; `Supr` quita las filas seleccionadas.
