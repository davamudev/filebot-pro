## Crear

<Steps>

1. Suelta los archivos que quieras proteger (o una carpeta) sobre la tabla. Cada archivo se calcula en cuanto se añade.

2. Elige el tipo de suma debajo de la tabla: **SFV**, **MD5**, **SHA1**, **SHA2** o **SHA3**.

3. Pulsa **Save as ...** y elige dónde guardar el archivo.

</Steps>

| Botón | Algoritmo | Archivo |
| --- | --- | --- |
| SFV | CRC32 | `.sfv` |
| MD5 | MD5 | `.md5` |
| SHA1 | SHA-1 | `.sha1` |
| SHA2 | SHA-256 | `.sha256` |
| SHA3 | SHA3-384 | `.sha3` |

Las rutas del archivo guardado son relativas a la carpeta donde lo guardas, así que se puede guardar en cualquier
sitio (los archivos de otra unidad conservan su ruta completa). Los archivos SFV usan saltos de línea de Windows y
los MD5 y SHA saltos de línea de Unix, como `md5sum`. Los archivos cuya suma aún se está calculando se omiten, con
un aviso.

Cambiar el tipo de suma recalcula la tabla. **Clear** la vacía; `Supr` quita las filas seleccionadas.

## Comprobar

<Steps>

1. Suelta un archivo de sumas (`.sfv`, `.md5`, `.sha1`, `.sha256` o `.sha3`) o la carpeta entera sobre la tabla. Los
   archivos de suma se comprueban con los archivos que tienen al lado, y los demás archivos se calculan.

2. Lee la columna **State** de cada archivo:

   | Estado | Significado |
   | --- | --- |
   | OK | La suma coincide |
   | WARNING | El CRC32 del nombre del archivo (p. ej. `[A1B2C3D4]`) no coincide con el archivo |
   | ERROR | El archivo de sumas y el archivo no coinciden, o el archivo no se pudo leer |

</Steps>

Un CRC32 en el nombre de un archivo (por ejemplo `[A1B2C3D4]`) también se comprueba, así que una versión se
puede verificar sin archivo de sumas.
